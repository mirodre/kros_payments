# SSO prihlásenie + serverové KROS prepojenia – implementačný plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Financie (kros_payments) vyžaduje prihlásenie cez login.krosdoplnky.sk a KROS prepojenia + webhooky drží v Postgrese pod organizáciou.

**Architecture:** Express app sa rozloží do `src/` modulov zložených v `createApp(deps)`. DB vrstva má jedno rozhranie (`query`/`exec`/`withClient`) nad `pg` (produkcia) aj PGlite (testy, dev). Session je serverová (vlastný šifrovaný store v DB), OAuth2 + PKCE klient je vlastný. Frontend prestane držať tokeny a posiela len `X-Kros-Connection`.

**Tech Stack:** Node ≥ 20 (lokálne 26), Express 4, express-session, pg, http-proxy-middleware 3, @electric-sql/pglite (dev), `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-12-sso-login-design.md`

## Global Constraints

- Plain JavaScript ESM, bez build kroku, bez TypeScriptu.
- Produkčné závislosti navyše len: `express-session`, `pg`. Dev: `@electric-sql/pglite`.
- Doména: `https://financie.krosdoplnky.sk`; app key `financie`; callback `https://financie.krosdoplnky.sk/auth/sso/callback`.
- Auth service: `https://login.krosdoplnky.sk`, endpointy `/oauth/authorize`, `/oauth/token`, `/api/me`, `/logout?app=financie&path=/`.
- Claims TTL 900 s, grace 86400 s, timeout volaní auth service 5 s.
- Session cookie `financie_sid`, `HttpOnly`, `SameSite=Lax`, `Secure` keď `APP_URL` je https, maxAge 30 dní.
- KROS consent: `https://firma.kros.sk/integration-consent`, `plugin_name=PlatformaUhrady`, `integrator_name=PlatformaUhrady`, `version=1`, `response_mode=post`, `company_mode=multiple`.
- Nikdy nelogovať tokeny, secrety, `code`, `code_verifier`.
- Texty v UI po slovensky.
- Testy: `npm test` = `node --test`; testy nesmú potrebovať sieť mimo 127.0.0.1.

## Review Focus

1. **Paralelné požiadavky pri expirovaných claims** – frontend pustí naraz viac `/api/*`; auth service rotuje refresh tokeny, takže druhý refresh by dostal `invalid_grant` a používateľa odhlásil. Očakávanie: jeden refresh na session, ostatné ho počkajú (test v Task 7).
2. **Únik session cookie na KROS** – generický proxy nesmie poslať `cookie`/`origin`/`x-kros-connection` na KROS ani vrátiť `set-cookie` z KROS (test v Task 10).
3. **Open redirect cez `/login?return=`** – `//evil.com`, `https://evil.com`, `/\evil.com` sa musia ignorovať (test v Task 6).
4. **Rozlíšenie 401** – naše `unauthenticated` → redirect na login; KROS 401 (zlý token firmy) → hláška, nie odhlásenie ani zmazanie prepojenia (test servera v Task 10, frontend v Task 12).
5. **Opakovaný / expirovaný consent `state`** – druhý POST s rovnakým `state` nesmie prepísať prepojenia ani ich priradiť inej organizácii (test v Task 8).

```js
const REQUIRED = [
  'APP_URL',
  'DATABASE_URL',
  'SESSION_SECRET',
  'APP_ENCRYPTION_KEY',
  'AUTH_SERVICE_URL',
  'AUTH_SERVICE_CLIENT_ID',
  'AUTH_SERVICE_CLIENT_SECRET',
  'AUTH_SERVICE_REDIRECT_URI',
];

const stripSlash = (s) => String(s).replace(/\/+$/, '');

export function loadConfig(env = process.env) {
  const missing = REQUIRED.filter((name) => !String(env[name] ?? '').trim());
  if (missing.length) {
    throw new Error(`Chýbajú povinné env premenné: ${missing.join(', ')}`);
  }
  if (env.SESSION_SECRET.length < 32) {
    throw new Error('SESSION_SECRET musí mať aspoň 32 znakov.');
  }
  const encryptionKey = Buffer.from(env.APP_ENCRYPTION_KEY, 'base64');
  if (encryptionKey.length !== 32) {
    throw new Error('APP_ENCRYPTION_KEY musí byť 32 bajtov v base64 (napr. `openssl rand -base64 32`).');
  }
  const appUrl = stripSlash(env.APP_URL);
  return {
    appUrl,
    appOrigin: new URL(appUrl).origin,
    port: Number(env.PORT) || 3000,
    databaseUrl: env.DATABASE_URL,
    sessionSecret: env.SESSION_SECRET,
    encryptionKey,
    secureCookies: appUrl.startsWith('https://'),
    authService: {
      url: stripSlash(env.AUTH_SERVICE_URL),
      clientId: env.AUTH_SERVICE_CLIENT_ID,
      clientSecret: env.AUTH_SERVICE_CLIENT_SECRET,
      redirectUri: env.AUTH_SERVICE_REDIRECT_URI,
      appKey: env.AUTH_SERVICE_APP_KEY || 'financie',
      claimsTtlMs: 900_000,
      gracePeriodMs: 86_400_000,
      timeoutMs: 5000,
    },
    krosApiBase: stripSlash(env.KROS_API_BASE || 'https://api-economy.kros.sk'),
    krosConsentUrl: 'https://firma.kros.sk/integration-consent',
  };
}
```

```js
/** Kryptografické pomôcky: náhodné tokeny, PKCE, AES-256-GCM. */
import crypto from 'node:crypto';

export function randomToken(bytes = 32) {
  return crypto.randomBytes(bytes).toString('base64url');
}

export function pkceChallenge(verifier) {
  return crypto.createHash('sha256').update(verifier).digest('base64url');
}

/** Formát: v1.<iv>.<tag>.<ciphertext> (všetko base64url). */
export function encrypt(plain, key) {
  const iv = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);
  const ct = Buffer.concat([cipher.update(String(plain), 'utf8'), cipher.final()]);
  const tag = cipher.getAuthTag();
  return ['v1', iv.toString('base64url'), tag.toString('base64url'), ct.toString('base64url')].join('.');
}

export function decrypt(payload, key) {
  const parts = String(payload).split('.');
  if (parts.length !== 4 || parts[0] !== 'v1') throw new Error('Neplatný formát šifrovaných dát.');
  const [, iv, tag, ct] = parts.map((p, i) => (i === 0 ? p : Buffer.from(p, 'base64url')));
  const decipher = crypto.createDecipheriv('aes-256-gcm', key, iv);
  decipher.setAuthTag(tag);
  return Buffer.concat([decipher.update(ct), decipher.final()]).toString('utf8');
}

export function safeEqual(a, b) {
  const x = Buffer.from(String(a ?? ''));
  const y = Buffer.from(String(b ?? ''));
  if (x.length === 0 || x.length !== y.length) return false;
  return crypto.timingSafeEqual(x, y);
}
```

`src/db.js`:

```js
/**
 * Spoločné DB rozhranie nad `pg` (produkcia) a PGlite (testy, lokálny vývoj).
 * DATABASE_URL: postgres://…  |  pglite:memory  |  pglite:<cesta k adresáru>
 */
import fs from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const MIGRATIONS_DIR = path.join(path.dirname(fileURLToPath(import.meta.url)), '..', 'migrations');
const MIGRATION_LOCK_ID = 727001;

export async function createDb(databaseUrl) {
  if (databaseUrl.startsWith('pglite:')) {
    const { PGlite } = await import('@electric-sql/pglite');
    const location = databaseUrl.slice('pglite:'.length);
    if (location && location !== 'memory') await fs.mkdir(location, { recursive: true });
    const pg = new PGlite(location && location !== 'memory' ? location : undefined);
    await pg.waitReady;
    const db = {
      async query(text, params = []) {
        const r = await pg.query(text, params);
        return { rows: r.rows, rowCount: r.affectedRows ?? r.rows.length };
      },
      async exec(sql) {
        await pg.exec(sql);
      },
      withClient: (fn) => fn(db),
      close: () => pg.close(),
    };
    return db;
  }

  const { default: pg } = await import('pg');
  const pool = new pg.Pool({ connectionString: databaseUrl, max: 10 });
  pool.on('error', (err) => console.error('[db] pool error:', err.message));
  const wrap = (c) => ({
    query: (text, params = []) => c.query(text, params),
    exec: async (sql) => { await c.query(sql); },
  });
  return {
    ...wrap(pool),
    async withClient(fn) {
      const client = await pool.connect();
      try {
        return await fn(wrap(client));
      } finally {
        client.release();
      }
    },
    close: () => pool.end(),
  };
}

/** Aplikuje nové migrations/*.sql v abecednom poradí; chránené advisory lockom. */
export async function migrate(db, dir = MIGRATIONS_DIR) {
  return db.withClient(async (c) => {
    await c.exec(`create table if not exists schema_migrations (
      name text primary key, applied_at timestamptz not null default now())`);
    await c.query('select pg_advisory_lock($1)', [MIGRATION_LOCK_ID]);
    try {
      const done = new Set((await c.query('select name from schema_migrations')).rows.map((r) => r.name));
      const files = (await fs.readdir(dir)).filter((f) => f.endsWith('.sql')).sort();
      const applied = [];
      for (const file of files) {
        if (done.has(file)) continue;
        const sql = await fs.readFile(path.join(dir, file), 'utf8');
        await c.exec('begin');
        try {
          await c.exec(sql);
          await c.query('insert into schema_migrations(name) values ($1)', [file]);
          await c.exec('commit');
        } catch (err) {
          await c.exec('rollback').catch(() => {});
          throw new Error(`Migrácia ${file} zlyhala: ${err.message}`);
        }
        applied.push(file);
      }
      return applied;
    } finally {
      await c.query('select pg_advisory_unlock($1)', [MIGRATION_LOCK_ID]);
    }
  });
}
```

```js
/** express-session store v tabuľke `sessions`; dáta šifrované (obsahujú refresh token). */
import session from 'express-session';
import { encrypt, decrypt } from './crypto.js';

const DEFAULT_TTL_MS = 30 * 24 * 60 * 60 * 1000;

export class DbSessionStore extends session.Store {
  constructor(db, { key, ttlMs = DEFAULT_TTL_MS }) {
    super();
    this.db = db;
    this.key = key;
    this.ttlMs = ttlMs;
  }

  expiresAt(sess) {
    const exp = sess?.cookie?.expires ? new Date(sess.cookie.expires) : null;
    return exp && !Number.isNaN(exp.getTime()) ? exp : new Date(Date.now() + this.ttlMs);
  }

  get(sid, cb) {
    this.db.query('select data from sessions where sid = $1 and expires_at > now()', [sid])
      .then(({ rows }) => {
        if (!rows[0]) return cb(null, null);
        try {
          cb(null, JSON.parse(decrypt(rows[0].data, this.key)));
        } catch {
          cb(null, null);
        }
      }, cb);
  }

  set(sid, sess, cb = () => {}) {
    this.db.query(
      `insert into sessions (sid, data, expires_at) values ($1, $2, $3)
       on conflict (sid) do update set data = excluded.data, expires_at = excluded.expires_at`,
      [sid, encrypt(JSON.stringify(sess), this.key), this.expiresAt(sess)],
    ).then(() => cb(null), cb);
  }

  touch(sid, sess, cb = () => {}) {
    this.db.query('update sessions set expires_at = $2 where sid = $1', [sid, this.expiresAt(sess)])
      .then(() => cb(null), cb);
  }

  destroy(sid, cb = () => {}) {
    this.db.query('delete from sessions where sid = $1', [sid]).then(() => cb(null), cb);
  }

  async pruneExpired() {
    const { rowCount } = await this.db.query('delete from sessions where expires_at <= now()');
    return rowCount;
  }
}
```

```js
export class AuthServiceError extends Error {
  constructor(kind, message, status) {
    super(message);
    this.name = 'AuthServiceError';
    this.kind = kind;
    this.status = status;
  }
}

export function createAuthServiceClient({ url, clientId, clientSecret, redirectUri, timeoutMs }, fetchImpl = fetch) {
  async function call(path, init) {
    let res;
    try {
      res = await fetchImpl(url + path, { ...init, signal: AbortSignal.timeout(timeoutMs) });
    } catch (err) {
      throw new AuthServiceError('unavailable', `Auth service nedostupný: ${err.name}`);
    }
    let body = null;
    try {
      body = await res.json();
    } catch {
      body = null;
    }
    if (res.status >= 500) throw new AuthServiceError('unavailable', `Auth service vrátil ${res.status}`, res.status);
    if (res.status === 401) throw new AuthServiceError('unauthorized', 'Neplatný token', 401);
    if (res.status === 400 && body?.error === 'invalid_grant') {
      throw new AuthServiceError('invalid_grant', 'Neplatný grant', 400);
    }
    if (!res.ok || !body) throw new AuthServiceError('bad_response', `Neočakávaná odpoveď ${res.status}`, res.status);
    return body;
  }

  async function token(params, previousRefreshToken) {
    const body = await call('/oauth/token', {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded', Accept: 'application/json' },
      body: new URLSearchParams({ client_id: clientId, client_secret: clientSecret, ...params }),
    });
    if (!body.access_token) throw new AuthServiceError('bad_response', 'Chýba access_token');
    return {
      accessToken: body.access_token,
      refreshToken: body.refresh_token || previousRefreshToken,
      expiresAt: Date.now() + (Number(body.expires_in) || 900) * 1000,
    };
  }

  return {
    authorizeUrl({ state, codeChallenge }) {
      const params = new URLSearchParams({
        client_id: clientId,
        redirect_uri: redirectUri,
        response_type: 'code',
        code_challenge: codeChallenge,
        code_challenge_method: 'S256',
        state,
      });
      return `${url}/oauth/authorize?${params}`;
    },
    exchangeCode({ code, codeVerifier }) {
      return token({ grant_type: 'authorization_code', redirect_uri: redirectUri, code, code_verifier: codeVerifier });
    },
    refresh(refreshToken) {
      return token({ grant_type: 'refresh_token', refresh_token: refreshToken }, refreshToken);

    async me(accessToken) {
```

```js
/** Minimalistický „prehliadač“: cookie jar per host + ručné sledovanie redirectov. */
export function createBrowser() {
  const jars = new Map();
  const jar = (host) => {
    if (!jars.has(host)) jars.set(host, new Map());
    return jars.get(host);
  };

  async function request(url, init = {}) {
    const u = new URL(url);
    const cookies = [...jar(u.host)].map(([k, v]) => `${k}=${v}`).join('; ');
    const headers = { ...(init.headers || {}) };
    if (cookies) headers.cookie = cookies;
    const res = await fetch(u, { ...init, headers, redirect: 'manual' });
    for (const line of res.headers.getSetCookie()) {
      const [pair, ...attrs] = line.split(';').map((s) => s.trim());
      const idx = pair.indexOf('=');
      const name = pair.slice(0, idx);
      const value = pair.slice(idx + 1);
      const expired = attrs.some((a) => /^max-age=0$/i.test(a) || (/^expires=/i.test(a) && new Date(a.slice(8)) < new Date()));
      if (expired || value === '') jar(u.host).delete(name);
      else jar(u.host).set(name, value);
    }
    return res;
  }

  async function follow(url, init) {
    let current = url;
    let res = await request(current, init);
    for (let i = 0; i < 10 && [301, 302, 303, 307, 308].includes(res.status); i++) {
      current = new URL(res.headers.get('location'), current).toString();
      res = await request(current);
    }
    return { res, url: current };
  }

  return { request, follow, cookies: (host) => new Map(jar(host)) };
}
```

```js
import { randomToken, pkceChallenge, safeEqual } from '../crypto.js';
import { upsertUser, upsertOrganizations } from '../repos.js';
import { renderAuthPage } from './pages.js';

export const SESSION_COOKIE = 'financie_sid';

export function safeReturnPath(value) {
  if (typeof value !== 'string' || value.length === 0 || value.length > 2000) return null;
  if (!value.startsWith('/') || value.startsWith('//') || value.startsWith('/\\')) return null;
  return value;
}

export function createAuthRouter({ config, db, authClient, now }) {
  const router = Router();
  const page = (res, status, kind) =>
    res.status(status).type('html').send(renderAuthPage(kind, { authServiceUrl: config.authService.url }));

  router.get('/login', (req, res, next) => {
    const state = randomToken();
    const verifier = randomToken(48);
    req.session.sso = { state, verifier, returnTo: safeReturnPath(req.query.return) };
    req.session.save((err) => {
      if (err) return next(err);
      res.redirect(authClient.authorizeUrl({ state, codeChallenge: pkceChallenge(verifier) }));
    });
  });

  router.get('/auth/sso/callback', async (req, res, next) => {
    const sso = req.session.sso;
    delete req.session.sso;
    const { code, state, error } = req.query;
    if (error || !sso || typeof code !== 'string' || typeof state !== 'string' || !safeEqual(sso.state, state)) {
      return page(res, 400, 'failed');
    }
    let tokens;
    let claims;
    try {
      tokens = await authClient.exchangeCode({ code, codeVerifier: sso.verifier });
      claims = await authClient.me(tokens.accessToken);
    } catch (err) {
      console.warn('[auth] callback zlyhal:', err.kind || err.message);
      return page(res, err.kind === 'unavailable' ? 503 : 400, err.kind === 'unavailable' ? 'unavailable' : 'failed');
    }
    if (!claims.email_verified) return page(res, 403, 'unverified');
    if (!claims.active_organization) return page(res, 403, 'no_org');

    try {
      await upsertUser(db, claims);
      await upsertOrganizations(db, claims.organizations);
    } catch (err) {
      return next(err);
    }
    req.session.regenerate((err) => {
      if (err) return next(err);
      req.session.auth = { tokens, claims, claimsFetchedAt: now() };
      req.session.save((saveErr) => {
        if (saveErr) return next(saveErr);
        res.redirect(sso.returnTo || '/');
      });
    });
  });

  router.post('/logout', (req, res) => {
    req.session.destroy(() => {
      res.clearCookie(SESSION_COOKIE);
      res.redirect(303, authClient.logoutUrl(config.authService.appKey));
    });
  });

  return router;
}
```

```js
export function unauthenticated(req, res) {
  if (req.originalUrl.startsWith('/api/')) return res.status(401).json({ error: 'unauthenticated' });
  return res.redirect(`/login?return=${encodeURIComponent(req.originalUrl)}`);

function attachUser(req, claims) {
  req.user = { id: claims.sub, email: claims.email, name: claims.name };
  req.organizationId = claims.active_organization;
  const org = claims.organizations.find((o) => o.id === claims.active_organization);
  req.organization = { id: claims.active_organization, name: org?.name || '' };
}

export function createRequireAuth() {
  return function requireAuth(req, res, next) {
    const auth = req.session?.auth;
    if (!auth) return unauthenticated(req, res);
    attachUser(req, auth.claims);
    next();
  };
}

const SAFE_METHODS = new Set(['GET', 'HEAD', 'OPTIONS']);

export function requireSameOrigin(appOrigin) {
  return function sameOrigin(req, res, next) {
    if (SAFE_METHODS.has(req.method)) return next();
    const origin = req.get('origin');
    const referer = req.get('referer');
    const ok = origin ? origin === appOrigin : (!referer || referer.startsWith(`${appOrigin}/`));
    if (!ok) return res.status(403).json({ error: 'forbidden_origin' });
    next();
  };
}
```

```js
import { upsertUser, upsertOrganizations } from '../repos.js';

// Single-flight: auth service rotuje refresh tokeny, paralelné refreshe jednej session by sa navzájom zneplatnili.
const inflight = new Map();

function refreshOnce(key, fn) {
  if (!inflight.has(key)) {
    inflight.set(key, fn().finally(() => inflight.delete(key)));
  }
  return inflight.get(key);
}

export function createRequireAuth({ config, db, authClient, now }) {
  const { claimsTtlMs, gracePeriodMs } = config.authService;

  async function refresh(auth) {
    const tokens = await authClient.refresh(auth.tokens.refreshToken);
    const claims = await authClient.me(tokens.accessToken);
    await upsertUser(db, claims);
    await upsertOrganizations(db, claims.organizations);
    return { tokens, claims, claimsFetchedAt: now() };
  }

  return async function requireAuth(req, res, next) {
    const auth = req.session?.auth;
    if (!auth) return unauthenticated(req, res);

    if (now() - auth.claimsFetchedAt >= claimsTtlMs) {
      try {
        const fresh = await refreshOnce(auth.tokens.refreshToken, () => refresh(auth));
        if (!fresh.claims.email_verified || !fresh.claims.active_organization) {
          return req.session.destroy(() => unauthenticated(req, res));
        }
        req.session.auth = fresh;
      } catch (err) {
        const withinGrace = err.kind === 'unavailable' && now() - auth.claimsFetchedAt < gracePeriodMs;
        if (!withinGrace) {
          console.warn('[auth] odhlasujem po zlyhaní refreshu:', err.kind || err.message);
          return req.session.destroy(() => unauthenticated(req, res));
        }
      }
    }
    attachUser(req, req.session.auth.claims);
    next();
  };
}
```

```js
/**
 * Prepojenie s KROS (integration consent). KROS vracia výsledok cross-site POST-om,
 * pri ktorom prehliadač nepošle SameSite=Lax cookie → väzba na organizáciu cez `state` v DB.
 */
import express, { Router } from 'express';
import { encrypt, randomToken } from '../crypto.js';
import { getOrganization, createConsentRequest, consumeConsentRequest, upsertConnection } from '../repos.js';

function normalizeCallbackCompany(company) {
  return {
    companyId: Number(company?.companyId),
    companyName: String(company?.companyName || ''),
    token: String(company?.token || ''),
    webhookSecret: company?.webhookSecret ? String(company.webhookSecret) : undefined,
  };
}

const isComplete = (c) => Number.isFinite(c.companyId) && c.companyName && c.token;

export function parseCallbackCompanies(body) {
  if (!body || typeof body !== 'object') return [];
  // extended: true (qs): data[0][pole]=… → { data: [ { pole: … } ] }
  if (Array.isArray(body.data) && body.data.length > 0) {
    return body.data.map(normalizeCallbackCompany).filter(isComplete);
  }
  const grouped = new Map();
  const keyRegex = /^data\[(\d+)\]\[(companyId|companyName|token|webhookSecret)\]$/;
  for (const [key, rawValue] of Object.entries(body)) {
    const match = key.match(keyRegex);
    if (!match) continue;
    const idx = Number(match[1]);
    grouped.set(idx, { ...(grouped.get(idx) || {}), [match[2]]: String(rawValue ?? '') });
  }
  return [...grouped.entries()]
    .sort((a, b) => a[0] - b[0])
    .map(([, company]) => normalizeCallbackCompany(company))
    .filter(isComplete);
}

export function createConsentCallbackRouter({ config, db }) {
  const router = Router();

  router.post('/kros/callback', express.urlencoded({ extended: true }), async (req, res, next) => {
    try {
      res.setHeader('Cache-Control', 'no-store');
      const state = typeof req.body?.state === 'string' ? req.body.state : '';
      const request = state ? await consumeConsentRequest(db, state) : null;
      if (!request) return res.redirect(303, '/?kros_error=state');
      const companies = parseCallbackCompanies(req.body);
      if (companies.length === 0) return res.redirect(303, '/?kros_error=empty');
      for (const c of companies) {
        await upsertConnection(db, {
          organizationId: request.organizationId,
          krosCompanyId: String(c.companyId),
          companyName: c.companyName,
          tokenEnc: encrypt(c.token, config.encryptionKey),
          webhookSecretEnc: c.webhookSecret ? encrypt(c.webhookSecret, config.encryptionKey) : null,
          createdByUserId: request.userId,
        });
      }
      res.redirect(303, `/?kros_connected=${companies.length}`);
    } catch (err) {
      next(err);
    }
  });

  router.get('/kros/callback', (req, res) => res.redirect('/'));
  return router;
}

export function createConnectRouter({ config, db, requireAuth }) {
  const router = Router();
  router.get('/kros/connect', requireAuth, async (req, res, next) => {
    try {
      const org = await getOrganization(db, req.organizationId);
      const state = randomToken();
      await createConsentRequest(db, { state, organizationId: req.organizationId, userId: req.user.id });
      const params = new URLSearchParams({
        plugin_name: 'PlatformaUhrady',
        integrator_name: 'PlatformaUhrady',
        version: '1',
        response_mode: 'post',
        redirect_url: `${config.appUrl}/kros/callback`,
        company_mode: 'multiple',
        state,
      });
      // KROS prijíma webhook len cez HTTPS.
      if (config.appUrl.startsWith('https://')) {
        params.set('webhook', `${config.appUrl}/kros/payments-callback/${org.webhookKey}`);
      }
      res.redirect(`${config.krosConsentUrl}?${params}`);
    } catch (err) {
      next(err);
    }
  });
  return router;
}
```

```js
/** Webhook s výsledkami spracovania platieb z KROS. */
import express, { Router } from 'express';
import crypto from 'node:crypto';
import { decrypt, safeEqual } from '../crypto.js';
import { findOrganizationByWebhookKey, listConnectionSecrets, insertCallback } from '../repos.js';

/**
 * KROS podpisuje telo webhook secretom („HMACSHA256, Base64, UTF-16LE“). Presný tvar
 * overíme na reálnom webhooku – dovtedy akceptujeme rozumné varianty kódovania.
 */
export function verifyKrosSignature(rawBody, secret, header) {
  if (!header || !secret) return false;
  const provided = String(header).trim().replace(/^sha256=/i, '');
  if (!provided) return false;
  const bodyText = rawBody.toString('utf8');
  const messages = [Buffer.from(bodyText, 'utf16le'), rawBody];
  const keys = [Buffer.from(secret, 'utf8'), Buffer.from(secret, 'utf16le')];
  for (const key of keys) {
    for (const msg of messages) {
      const mac = crypto.createHmac('sha256', key).update(msg).digest();
      if (safeEqual(mac.toString('base64'), provided)) return true;
      if (safeEqual(mac.toString('hex'), provided.toLowerCase())) return true;
    }
  }
  return false;
}

function parsePayload(raw) {
  const text = raw.toString('utf8');
  if (!text) return {};
  try {
    return JSON.parse(text);
  } catch {
    return { raw: text.slice(0, 100_000) };
  }
}

export function createWebhookRouter({ config, db }) {
  const router = Router();
  const paths = ['/kros/payments-callback/:key', '/kros/payments-callback/:key/*'];

  // Starý endpoint bez kľúča: KROS ho mal zaregistrovaný pred prechodom na prihlasovanie.
  router.post('/kros/payments-callback', (req, res) => {
    console.warn('[kros-webhook] webhook na starú URL bez kľúča – zahadzujem (treba nové prepojenie)');
    res.status(200).json({ ok: true, ignored: true });
  });

  router.get(paths, async (req, res, next) => {
    try {
      const org = await findOrganizationByWebhookKey(db, req.params.key);
      if (!org) return res.status(404).json({ ok: false });
      res.json({ ok: true, message: 'Webhook endpoint pre výsledky platieb je pripravený (očakáva POST).' });
    } catch (err) {
      next(err);
    }
  });

  router.post(paths, express.raw({ type: () => true, limit: '2mb' }), async (req, res, next) => {
    try {
      const org = await findOrganizationByWebhookKey(db, req.params.key);
      if (!org) return res.status(404).json({ ok: false });
      const raw = Buffer.isBuffer(req.body) ? req.body : Buffer.alloc(0);
      const signature = req.get('x-kros-signature-256') || null;
      let connectionId = null;
      for (const c of await listConnectionSecrets(db, org.id)) {
        let secret;
        try {
          secret = decrypt(c.webhookSecretEnc, config.encryptionKey);
        } catch {
          continue;
        }
        if (verifyKrosSignature(raw, secret, signature)) {
          connectionId = c.id;
          break;
        }
      }
      if (!connectionId) console.warn('[kros-webhook] neplatný alebo chýbajúci podpis, organizácia %s', org.id);
      await insertCallback(db, {
        organizationId: org.id,
        connectionId,
        signatureHeader: signature,
        signatureValid: Boolean(connectionId),
        payload: parsePayload(raw),
      });
      // KROS musí dostať rýchlu 200, inak bude webhook opakovať.
      res.status(200).json({ ok: true });
    } catch (err) {
      next(err);
    }
  });

  return router;
}
```

```js
async function processKrosConnectResult() {
  const params = new URLSearchParams(window.location.search);
  const connected = params.get('kros_connected');
  const error = params.get('kros_error');
  if (!connected && !error) return;
  params.delete('kros_connected');
  params.delete('kros_error');
  const nextQuery = params.toString();
  window.history.replaceState({}, '', `${window.location.pathname}${nextQuery ? `?${nextQuery}` : ''}`);

  if (error === 'state') {
    showPickerConnectInfo('Prepojenie sa nepodarilo overiť (vypršal čas alebo bolo už použité). Skúste to znova.', 'error');
    return;
  }
  if (error) {
    showPickerConnectInfo('KROS nevrátil žiadnu firmu na prepojenie.', 'error');
    return;
  }
  showPickerConnectInfo(`Prepojenie hotové: ${Number(connected) || 0} firiem. Overujem prístup...`, 'success');
  await connect();
}

/** Overí prístup aktívnej firmy cez KROS (/api/auth/check). */
async function connect() {
  const errBox = document.getElementById('module-picker-error');
  if (errBox) errBox.hidden = true;
  try {
    if (!getActiveCompanyConnection()) {
      showError('module-picker-error', 'Najprv sa prepojte s KROS tlačidlom vyššie.');
      return;
    }
    const authSignal = fetchTimeoutSignal(45000);
    await apiCall('/api/auth/check', { method: 'GET', ...(authSignal ? { signal: authSignal } : {}) });
    hidePickerConnectInfo();
    updateActiveCompanyLabels(getActiveCompanyConnection());
    showModulePicker();
  } catch (e) {
    if (e?.status === 'unauthenticated') return;
    if (e?.name === 'AbortError' || e?.name === 'TimeoutError') {
      showError('module-picker-error', 'KROS API neodpovedalo včas (45 s). Skúste znova o chvíľu.');
    } else if (e.status === 401) {
      await showDisconnectedModulePicker();
    } else {
      showError('module-picker-error', formatApiError(e, 'Overenie prepojenia zlyhalo'), true);
    }
  } finally {
    resetKrosConnectButton();
    updateModulePickerLockState();
  }
}

async function handleModuleCompanyChange() {
  const select = document.getElementById('module-company-select');
  if (!select) return;
  const conn = state.connections.find((c) => c.id === select.value);
  if (!conn) return;
  hideModulePickerInfo();
  setActiveCompanyConnection(conn);
  try {
    await apiCall('/api/auth/check', { method: 'GET' });
    conn.invalid = false;
    showModulePickerInfo(`Aktívna firma: ${escapeHtml(conn.companyName)}.`, 'success', true);
  } catch (e) {
    if (e?.status === 'unauthenticated') return;
    if (e?.status === 401) conn.invalid = true;
    showModulePickerInfo(formatApiError(e, 'Prepnutie firmy zlyhalo'), apiErrorType(e), true);

}

async function disconnectActiveCompany() {
  const conn = getActiveCompanyConnection();

}
```
